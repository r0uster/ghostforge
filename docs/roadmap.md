# Roadmap

- Finish the first improved-run public verification write-up.
- Test GhostForge on fullspeed maps.
- Expand experiments to grass, plastic, dirt, and ice.
- Improve distributed search efficiency.
- Investigate targeted trick/contact discovery.
- Eventually ingest maps and elite ghosts automatically.

Future standalone utilities may include `track-geometry-engine` and a Trackmania raycast/sensor toolkit. Each will require its own publication audit; neither is part of this repository yet.

Compiled GhostForge binaries are intentionally withheld pending a separately approved release candidate.
